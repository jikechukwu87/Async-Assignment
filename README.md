# Async Assignment

This project is a clean, single-page application built with React that demonstrates effective asynchronous data fetching and dynamic UI rendering. It gracefully retrieves and displays a list of random user profiles from an external API, providing a practical example of managing component state and side effects for real-world data interactions.

## Installation

To get this project up and running on your local machine, follow these simple steps:

1.  **Clone the Repository:**
    ```bash
    git clone https://github.com/jikechukwu87/Async-Assignment.git
    ```

2.  **Navigate to the Project Directory:**
    ```bash
    cd Async-Assignment
    ```

3.  **Install Dependencies:**
    ```bash
    npm install
    ```

4.  **Start the Development Server:**
    ```bash
    npm run dev
    ```

This will launch the application in development mode, usually accessible at `http://localhost:5173`.

## Usage

Once the development server is running, open your web browser and navigate to the address provided in your terminal (typically `http://localhost:5173`). You'll see a clean interface displaying a list of random user profiles, including their names, email addresses, and genders. The application handles fetching this data from an external API and rendering it dynamically.

## Features

*   **Asynchronous Data Fetching**: Demonstrates how to fetch data from an external API using `fetch` and `async/await`.
*   **Dynamic UI Rendering**: Renders a list of user profiles based on the fetched data.
*   **State Management**: Utilizes React's `useState` and `useEffect` hooks for managing application state and side effects.
*   **Basic Error Handling**: Includes a simple `try-catch` block for handling potential API call errors.
*   **Clean User Interface**: A straightforward and readable display of user information.
